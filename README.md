# freeform-typing

お題の無いローマ字タイピングゲームを作るためのリポジトリ。

## どんなゲームか（構想）

ふつうのタイピングゲームは「打つべき文」が画面に出る。このゲームではお題を出さず、プレイヤーが自由に日本語の文を打つ。
打った文は形態素解析と埋め込み（文や単語のベクトル）で評価され、得点のルールはカードとして途中で選んで足していく（デッキ構築型ローグライク）。
ルールの例:

- 固有名詞が入っていれば加点
- 前に打った文から意味が遠い文ほど加点
- 文の中の名詞どうしが意味的に離れているほど加点
- 前の文としりとりになっていれば倍率

序盤は自由に打つだけで、カードを足すほど「得点のために何を打つか」を考えるようになる。埋め込みの点はおまけのバフの位置づけ。

## いまあるもの: 評価のテストベンチ

ゲームはまだ無い。形態素解析と埋め込みが、人が予想できるように振る舞うかを確かめるための台だけがある。

- 文を打って送信すると履歴に積まれる（IME で漢字に変換してよい）
- kuromoji.js の解析結果（表層形・品詞・細分類・原形・読み・発音、固有名詞の印）
- transformers.js による文の埋め込み（既定は `Xenova/multilingual-e5-small`、モデル ID は画面で切り替えられる）と、直前の文・過去の全文とのコサイン類似度／距離
- 文中の名詞それぞれの埋め込みと、名詞どうしの距離の行列（最小・平均・最大）
- 前の文とのしりとり判定（判定の規則は画面に表示）
- 「ひらがな化して再解析」: 読みでひらがなだけの文にして解析し直し、元の文と並べて表示
- 履歴の JSON 書き出し・読み込み、エントリごとの生の JSON
- 得点ルールを JS の関数で書いて、履歴の全件で試す欄

すべてブラウザの中で動く（サーバー無し）。埋め込みモデルは初回に Hugging Face Hub から読み込み（既定の設定で約 135 MB）、以後はブラウザのキャッシュから読む。

公開版: https://ryokaringumi.github.io/freeform-typing/

## 手元で動かす

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に出力
npm run preview  # ビルド結果を確認
```

kuromoji の辞書は `npm run dev` / `npm run build` の前に `node_modules/kuromoji/dict` から `public/dict` へコピーされる（リポジトリには含めない）。
