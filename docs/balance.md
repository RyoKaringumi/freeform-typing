# 点の釣り合いの集計（2026-10-29）

ゲームの採点の関数（`src/game/cards.ts` の `scoreSentence`）に、用意した文例を直接通して多数のランを回し、ゲートとカードの数値を直した記録。集計のスクリプトは `tools/sim/`（`npm run sim -- --runs 300 --label after`）。

## 目標の形

- 序盤は、カード無しかカード 1〜2 枚で、ふつうの文を打てば越えられる。
- 中盤から先は、手持ちのカードに合わせて打つ文を考えないと越えにくい。
- 埋め込みのカード（話題転換・新境地・遠い名詞）は、数ある中の「おまけ」。点の大半を占めない。

## やり方

- 文例: 431 文（`tools/sim/corpus.ts`）。短文・ふつうの文・長文・固有名詞の多い文・カタカナ語の多い文・動詞の多い文・品詞のばらけた文・十七音を狙った文・話題がばらばらの文・遠い名詞を並べた文・いろいろな仮名で始まる文（しりとり用）・ひらがなだけの文。
- 打ち方（1 ランの中で、文例は一度ずつしか使えない）:
  - **ふつうに打つ**: カードを気にせず、ふつうの文（短文・ふつう・長文・固有名詞・カタカナ・話題・しりとり用・ひらがな）から無作為に打つ。
  - **少し考える**: 思いついた 8 文（無作為）のうち、いまのカードで一番点の高い文を打つ。
  - **よく考える**: 文例の全部から一番点の高い文を打つ（上限の目安）。
- カードの取り方: 取らない・無作為・貪欲（取ったあとの 1 文の点の見込みが一番上がるもの）・倍率× 寄せ・埋め込み寄せ・点寄せ（寄せる札が出ていなければ貪欲）。
- ラン数: 「ふつう」「少し考える」は各 300、「よく考える」は各 75。種は 1。
- 埋め込みは Node の transformers.js で ruri-v3-30m（q8、ゲームと同じモデル）。ブラウザ（wasm）とは小数の下の方がわずかに違いうる。

## 効きにくいカード・強い組み合わせ

- **品詞のパレット**: 前は「ふつうの文で 21% しか効かない」のに「狙うと 1 枚で 126 点」。後はふつうの文で 81〜85% 効き、狙ったときの上位 10 文は 90 点。
- **新境地**: ふつうに打つと t の中央値が 0.21〜0.25（このラウンドの文のどれか一つに近いと t が下がる仕組みのため）。考えて打つと 0.38〜0.50 に上がる。「考えると伸びる」形なので数値は変えていない。
- **遠い名詞**: 単語の埋め込みの t は名詞が 2 つあるだけで高く出やすい（中央値 0.75〜0.85）。上限を下げて「おまけ」にした。測り方そのもの（`src/game/distance.ts` の `farthestNounPair`）は差し替えやすくしてある。
- **しりとり・十七音**: ふつうの文ではまず効かない（1〜3%）。十七音は狙えば効き、「よく考える」で点の 2〜4 割を占める。しりとりは集計では「よく考える」でも 13〜17% しか効かない。文例が決まっているので前の文の最後の仮名で始まる文が少ないためで、人が文を作るならもっと効くはず（集計では過小に出ている）。
- 強い組み合わせ: 2 枚まとめて外すと減る点の上位は、後では 名詞あつめ・動詞の連鎖・品詞のパレット・長文の心得・十七音 の組で、どれも点の 5 割前後。一つの組だけが飛び抜けてはいない。前は 話題転換＋動詞の連鎖、遠い名詞＋名詞あつめ、十七音＋話題転換 と、埋め込みを含む組が上位だった。

## 集計で分からないこと

- 人は文を作れるが、集計は決まった文例から選ぶだけ。しりとりと十七音を同時に満たす文のように、条件を重ねた文は作れない。後半のゲートが人にとって厳しいか甘いかは、遊んで確かめる必要がある。
- 打つ速さ・疲れ・長文を打つ手間は数えていない（点に入れていないため）。
